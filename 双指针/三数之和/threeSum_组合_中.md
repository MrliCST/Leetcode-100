1. 容易想到的是回溯递归法,简称 **回溯法** ，是一种通过深度优先搜索（DFS）来穷举解决问题的算法思想。

```
def backtrack(路径, 选择列表):
if 满足结束条件:
结果集.add(路径)
return    for 选择 in 选择列表:
        # 1. 做选择
        路径.append(选择)        # 2. 递归进入下一层
        backtrack(路径, 新的选择列表)        # 3. 撤销选择（回溯的关键！）
        路径.pop()
```

2. 最优解是双指针法。固定一个数，剩下的两个数，用两个下标（L、R)同时在数组上移动，通过控制它们的移动方向，减少无效遍历。

记得去重：分为两层，固定的值去重和移动的指针去重。
